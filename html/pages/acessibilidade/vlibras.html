VLibras

Tradutor automático de conteúdo digital para Língua Brasileira de Sinais, promovendo a inclusão de pessoas surdas em ambientes digitais.

O que é o VLibras?

O VLibras é um conjunto de ferramentas computacionais de código aberto, desenvolvido pelo Ministério da Economia em parceria com a UFPB, que traduz conteúdos digitais (texto, áudio e vídeo) para a Língua Brasileira de Sinais (Libras), tornando a web mais acessível para a comunidade surda.

Plugin Web

Extensão para navegadores que traduz automaticamente qualquer página da web para Libras.

Acessar

App Mobile

Aplicativo gratuito para Android e iOS que permite tradução de textos e vídeos para Libras.

Como usar o VLibras neste site?

  1. 1
    Localize o ícone VLibras

    Procure o ícone de acessibilidade localizado no canto da tela.

  2. 2
    Clique para ativar

    Ao clicar, o avatar de Libras aparecerá e começará a traduzir o conteúdo.

  3. 3
    Navegue normalmente

    Todo o texto da página será traduzido automaticamente para Libras em tempo real.
