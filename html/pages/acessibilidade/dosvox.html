DOSVOX

Sistema computacional desenvolvido pela UFRJ para auxiliar deficientes visuais a utilizarem computadores com síntese de voz em português.

O que é o DOSVOX?

O DOSVOX é um sistema computacional para microcomputadores que se comunica com o usuário através de síntese de voz, viabilizando o uso de computadores por deficientes visuais. Desenvolvido pelo Núcleo de Computação Eletrônica (NCE) da UFRJ, é gratuito e amplamente utilizado no Brasil desde 1993.

Principais Recursos

Síntese de Voz em PT-BR

Leitura de tela totalmente em português brasileiro com voz natural e clara.

Editor de Textos (EDVOX)

Editor acessível para criação e edição de documentos de texto com suporte a voz.

Navegação Web (WEBVOX)

Navegador de internet adaptado com leitura de páginas web em voz alta.

Leitor de E-mail (CARTAVOX)

Cliente de e-mail acessível para envio e recebimento de mensagens.

Jogos Acessíveis

Jogos adaptados para deficientes visuais, promovendo lazer e estimulação cognitiva.

Suporte a Braille

Compatível com terminais Braille para leitura tátil do conteúdo da tela.
